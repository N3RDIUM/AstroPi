# AstroPi
A raspberry pi based astrophotography camera.

## Roadmap
- [ ] Design the camera. Don't bother with cooling just yet.
- [ ] Basic imaging (just preview + shutter) using hosted web ui
- [ ] Host subs on a samba server (write setup how-tos in md)
- [ ] Basic camera settings (exposure time, gain)
- [ ] Intervalometer-like automation (number of subs, interval)
- [ ] Support any camera module (yes, even webcams), maybe provide presets too
- [ ] Collimation assist (need to track stars as they move across the fov)
- [ ] Focus assist (exactly what it sounds like)
- [ ] Temperature readouts from the camera and the pi itself
- [ ] Implement the peltier-based sensor cooling system
